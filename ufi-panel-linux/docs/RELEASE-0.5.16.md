# UFI Panel Linux 0.5.16

历史监控原先把当日、当月累计流量画在同一张从零起算的图中。约 105 GB 的本月累计会把纵轴推到 200 GB；即使一小时新增 400 MB，180 像素高的图上也只增加约 0.32 像素，看起来像水平直线。

现在分别展示「当日累计流量」和「当月累计流量」，各自按所选范围内的有效读数缩放纵轴，并在图旁显示实际的上下限。纵轴标签会根据刻度间距调整小数位，避免较小增量导致所有刻度显示相同的总量。没有新增流量时仍保持水平线。

累计值、悬停读数和原始记录保持原来的统计口径。采集失败、断开连接和缺失读数处继续保留断点。已有本地历史无需迁移。

验证覆盖较大累计值上的小幅增量、恒定值、零值、计数器归零、查询范围、缺失采样、刻度精度，以及真实 WebKit 窗口中的累计图绘制和悬停读数。

# UFI Panel Linux 0.5.11

实时监控的速率、CPU 温度、CPU 使用率与内存使用率图表新增竖向参考线、采样点高亮和读数浮层。浮层显示对应采样的时间、数值与单位，缺失值显示“—”；参考线吸附实际记录，浮层在边缘自动换侧。

鼠标停在某张图表上时，该图表的曲线、刻度及卡片内的当前值保持不变，并提示“画面已固定 · 采样继续”。其他图表、设备状态、后台采样与 SQLite 历史记录继续更新。鼠标移出后，图表立即显示最新数据。切换页面、更换设备、断开连接、切换趋势范围或隐藏窗口会解除固定状态。调整窗口大小时按原采样重新排版，保持固定的数据与时间范围。

实时图表和历史图表共用悬停读数实现，按动画帧合并鼠标事件，复用未变化的读数与浮层尺寸。悬停仅作用于绘图和读数展示，不会调用暂停采集接口。

验证：Node 自动测试 87 项通过，新增显示范围与采样缓冲区分离的回归测试；浏览器覆盖四类实时图表、浅色和深色主题、1240/900 像素视口及 2 倍像素密度，检查读数、悬停固定、移出恢复、图表边缘和调整大小。

原生 WebKit 通过真实鼠标移动验证四张实时图表的浮层与画面固定，逐项确认连续采样时画布像素、悬停读数、卡片当前值保持不变，其他图表正常刷新，历史记录持续增加；一秒定时采样在悬停期间仍正常运行。移出、导航切换及缺失值显示检查通过。历史图表的浮层读数与完整历史持久化检查通过，原生界面交互回归检查通过。安装包内嵌的 49 项源码摘要与最终源码一致。

运行 `npm run test:live-charts` 可重放原生检查。报告见 `artifacts/validation-0.5.11.json`、`artifacts/live-charts-validation.json` 和 `artifacts/live-charts-browser-validation.json`，截图见 `artifacts/tauri-live-chart-hover.png`。

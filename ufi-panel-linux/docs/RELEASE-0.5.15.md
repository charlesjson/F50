# UFI Panel Linux 0.5.15

托盘状态窗口现在可以拖动。按住顶部「设备状态」和设备名称所在区域，即可移动整个窗口；该区域显示抓手光标。指标仍保持每项一行、名称／数值／单位按列对齐。拖动后窗口继续显示，点击其他窗口或按 Esc 自动收起；底部「打开管理台」按钮和托盘右键菜单沿用原有操作。

每次启动程序时，自动尝试连接上次使用的设备。仅当该设备已勾选「保存口令」且系统密钥环可用时尝试，凭据由后台解密，口令不会填入界面。连接成功后直接进入已有的设备状态和采样流程，插件配置页继续复用登录信息。

自动连接只尝试一次，不轮流连接其他已保存设备；失败时保留原配置并显示原因，可直接手动重试或输入更新后的口令。等待连接期间可打开连接对话框取消。未保存口令、未选择上次设备或密钥环不可用时，使用原有手动连接入口。

验证记录见 `artifacts/validation-0.5.15.json`。原生测试覆盖实际鼠标拖动、拖动后失焦隐藏，以及加密凭据在启动／重启时的恢复、失败和手动重试、失效口令更新、取消待完成连接和缺失凭据时跳过自动连接。

# UFI Panel Linux 0.5.9

历史图表悬停时，在竖向参考线旁直接显示对应采样的时间、当前图表的指标和单位。网速显示下载与上传，流量显示当日与当月累计，CPU、内存、温度分别显示各自的读数。

浮层沿用悬停采样选择的实际记录，百分比与温度保留一位小数。零值正常显示，缺失值显示“—”；汇总点显示采样时间范围和采样次数。浮层在左右边缘自动换侧，并保持在绘图区内，不拦截鼠标事件。移出图表、重新查询、调整大小或切换页面时，与参考线一同隐藏。

Node 自动测试 84 项通过。浏览器验证覆盖五类图表、浅色和深色主题、1040/620 像素视口及 2 倍像素密度，检查数值与单位、时间、零值、缺失值、汇总范围、边缘位置和移出隐藏。

原生 WebKit 使用 WebDriver 的真实鼠标移动验证通过：五类图表的浮层读数与记录表一致，移动参考线会更新选中采样，缺失速率不残留旧值；浮层在左右边缘和窄图表中保持可见，深色主题下文字可读；移出、重新查询、调整大小或离开历史页面后，与参考线一起隐藏。安装包内嵌的 47 项源码摘要与当前源码一致。

报告见 `artifacts/validation-0.5.9.json`、`artifacts/chart-tooltip-native-validation-0.5.9.json`、`artifacts/chart-tooltip-browser-validation-0.5.9.json`。效果图见 `artifacts/tauri-chart-tooltip-0.5.9.png`、`artifacts/tauri-chart-tooltip-dark-0.5.9.png`。

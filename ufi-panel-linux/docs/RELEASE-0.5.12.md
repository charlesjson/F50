# UFI Panel Linux 0.5.12

「系统 → 插件」新增通用的「配置页面」，复用 UFI-TOOLS 自己的插件脚本和网页环境，自动显示选中插件生成的按钮、输入框、表单、弹窗、iframe 及异步创建的内容。客户端按脚本来源追踪界面，不按插件名称、按钮文字或固定端口编写专属适配。插件声明的独立设置地址继续通过「设置面板」访问。

配置窗口保留原始 DOM、事件处理和文件选择器。切换「显示完整设备页面／返回插件配置」保留已填写的表单和 iframe 会话，方便完成设备网页登录。支持当前设备其他端口提供的内嵌 Web UI。相关折叠区域默认展开，空白界面提供等待提示和完整页面入口，脚本错误显示失败信息。

修复同一设备上切换插件时的窗口标识复用冲突，以及旧窗口回调影响新窗口备份下载的问题。备份仍保存到下载目录，使用随机文件名前缀且禁止覆盖。插件源代码只在独立设备 WebView 中运行，不能调用客户端的本机接口；设备切换、断开或插件修订变化会关闭旧配置窗口。

提供 x86_64 的 Arch / EndeavourOS、Debian / Ubuntu 和 Fedora 安装包。安装与升级命令见 [安装说明](../packaging/INSTALL-TAURI.md)，通用渲染约定见 [插件接入说明](PLUGIN-SETTINGS-DESIGN.md)。

验证：87 项 Node 测试、11 项 Rust 测试通过。三个安装包的原生程序一致，包内后端与 51 项内嵌源码摘要校验通过。直接使用 DEB 解出的程序通过通用插件配置、菜单发现与插件管理三组原生 WebKit 检查，包括所提供的猫猫、SSH 原始脚本、异步界面、不同端口 iframe、弹窗、文件上传、备份下载及旧会话失效。Debian 12 容器内升级安装后通过完整原生交互回归；Fedora 43 容器内升级安装后通过启动、自启动配置、缩放与剪贴板检查。全部设备写入测试使用本地模拟设备。

版本验证报告保存在 `artifacts/validation-0.5.12.json`，安装包校验值保存在 `release/SHA256SUMS`。

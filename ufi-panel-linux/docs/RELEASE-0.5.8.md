# UFI Panel Linux 0.5.8

修复概览和历史监控图表缺少纵坐标的问题。原绘制函数只显示横向网格，未绘制数值刻度；现在统一显示五档刻度与纵轴线，分别使用速率、百分比、温度或累计流量单位。

纵轴按实际文字宽度预留左侧空间，适配浅色、深色主题和高分屏。CPU 与内存保持 0–100% 范围，温度、速率和流量沿用原有的自动范围。历史图表根据实际绘图区换算鼠标位置，避免增加刻度后悬停读数偏移。

历史图表的悬停采样新增竖向虚线，跟随鼠标在绘图区内移动，对照同一位置的采样读数。参考线不拦截鼠标事件，移出图表、重新查询、调整图表大小或离开历史页面后隐藏。

验证：Node 自动测试 84 项通过；最小绘图复现由零个刻度变为五个刻度，检查百分比端点、速率和温度单位。浏览器渲染检查覆盖五种图表、浅色与深色主题及 2 倍像素密度，刻度在画布内显示。

原生 WebKit 验证通过：概览四张图表、历史五张图表的刻度和单位；五类历史图表的竖线位置、绘图区高度、鼠标移动与移出；两端悬停采样；重新查询、切换页面、调整大小后清除参考线；深色主题的参考线颜色。安装包内嵌的 47 项源码摘要与当前源码一致。

报告见 `artifacts/validation-0.5.8.json` 和 `artifacts/chart-axes-native-validation-0.5.8.json`，效果图见 `artifacts/tauri-chart-cursor-0.5.8.png`、`artifacts/tauri-chart-cursor-dark-0.5.8.png`。

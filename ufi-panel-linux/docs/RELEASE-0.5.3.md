# UFI Panel Linux 0.5.3

猫猫插件的「设置」现在直接打开独立的节点／策略组面板，默认地址为设备的 `7788/ui/#/proxies`，不再把用户带到 UFI-TOOLS 完整首页。

客户端只解析已安装插件中的字面量控制器连接信息，不执行插件源码。对于设备自己的面板，在网页启动前准备其控制器配置，首次打开即可连接；口令不会放入 URL 或插件列表摘要。自定义地址不会自动接收设备控制器口令。未提供可识别连接信息的插件会使用面板自身的连接配置页。

原来的「代理面板」按钮改为「连接地址」，用于自定义端口／反代入口。订阅、内核安装等旧插件工具保留在「管理 → 原生插件工具」，与节点管理明确区分。没有独立面板的插件显示「原生设置」。

新面板会话默认使用简体中文，已有语言偏好保留。0.5.2 的背景毛玻璃内存兼容修复继续生效，设备网页仍无法调用本机客户端接口。

验证包括：

- 全新 WebKitGTK 会话连接真实设备，直接显示「节点选择」「self 节点」「st 节点」，未显示 UFI 首页或要求 UFI 登录。
- 同一真实面板持续观测 90 秒，并保存截图；没有修改设备节点、策略组或配置。
- 原生 WebKit 交互检查直接路由、连接初始化、来源隔离、上传及 Blob 备份下载。
- 单元测试验证口令不进入摘要／URL、不向自定义地址或无关来源注入，并保留已有面板配置。

汇总：`artifacts/validation-0.5.3.json`；真机截图：`artifacts/cat-settings-0.5.3.png`。

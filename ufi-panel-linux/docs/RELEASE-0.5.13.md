# UFI Panel Linux 0.5.13

左下角新增常驻设备状态，显示 CPU 使用率、内存使用率、CPU 温度、今日流量、本月累计流量、实时下载／上传速率，以及设备报告的 Wi-Fi 接入数量。每项占一行，名称左对齐、数值右对齐，单位固定在单独的一列；读数使用等宽字体和等宽数字，刷新时保持列位置稳定。点击 Wi-Fi 数量可以进入连接终端列表。

侧栏使用现有后端采样流，不增加轮询、设备请求或后台任务。切换到其他页面、打开设置或悬停固定概览图表时，侧栏继续跟随最新采样。状态区显示更新时间；暂停采集显示「已暂停」，请求失败时保留最后一次成功读数并显示「数据过期」，断开连接或更换设备会清空旧读数。设备未提供的指标显示「—」，合法的零用量、零网速和零接入数正常显示。

浅色和深色主题均使用现有主题颜色；较矮窗口中压缩行间距，保持导航和底部设备信息可用。侧栏版本号改由构建时的应用版本生成，避免升级后仍显示旧版本。

验证：89 项 Node 测试通过。原生 WebKit 在 1240×800 和 1024×700 窗口、浅色和深色四种组合下检查八行指标的名称位置、数值右边界和单位列，以及文字和底部设备信息的可见性。覆盖合法零值、缺失读数、暂停、失败与恢复、切换设备、断开清空、导航快捷入口、切换页面继续采样和图表悬停时侧栏独立更新；确认一次手动采样仍只读取一组原有接口，不额外查询终端列表。实时图表及完整原生交互回归通过。三个安装包的程序与后端内容一致，52 项内嵌源码摘要校验通过。

验证报告见 `artifacts/validation-0.5.13.json`，安装说明见 [安装与升级](../packaging/INSTALL-TAURI.md)。

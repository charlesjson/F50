# 全量迁移规划

当前 0.5.5 的设备网页、APK 与源码差异已于 2026-10-17 重新核对，见 [最新功能差异审计](audit-20261017/README.md)。下方 115 项目录仍保留原规划基线；判断当前缺项请以新审计及源码证据为准。

- [交互原型](INTERACTION-PROTOTYPE.html)：可直接用浏览器打开的单文件 HTML，使用演示数据，不连接设备。
- [实施与交互方案](IMPLEMENTATION-PLAN.md)：全量范围、六组导航、模态层级、草稿、任务、后端结构及分阶段验收。
- [逐项功能矩阵](FEATURE-MATRIX.md)：115 个迁移/验收条目，包含现有功能及需进一步核实的关联证据项；43 个 APK 页面声明均有去向。
- [机器可读清单](feature-catalog.json)：固定功能 ID、APK 源码行、状态、后端约束、验收条件和实施依赖。

正式客户端已推进到 **0.5.0**，六组导航和多个缺项已实际落地。Tauri 迁移见 [0.5.0 说明](../RELEASE-0.5.0.md)，历史 Linux 安装包见 [打包说明](../LINUX-PACKAGING.md)，收发分类见 [0.4.3 说明](../RELEASE-0.4.3.md)，邻区、短信与模板交互见 [0.4.2 说明](../RELEASE-0.4.2.md)，持续监控见 [0.4.1 说明](../RELEASE-0.4.1.md)，此前功能见 [0.4.0 交付记录](../RELEASE-0.4.0.md)及 [逐项实现进度](implementation-status.json)。原型仍以 0.3.0 为规划基线，不是运行包。

用户确认当前只有 F50 / UFI-TOOLS 可作真机联调。其他模式保留在目标范围中，但真机验收状态不能由 F50 测试代替。

## 查看和复现

```sh
npm run plan:build
npm run plan:preview
npm run plan:check
```

预览服务器只绑定 `127.0.0.1`，终端会输出地址；结束预览时按 Ctrl+C。也可直接打开上面的独立 HTML，无需服务器。

可体验：六个主入口与二级导航、功能搜索、功能证据抽屉、Wi-Fi 编辑/草稿/变更确认、短信编辑/确认、RRC/NDJSON 示例、长任务中心、实施计划。

校验覆盖 6 个主入口和 29 个二级页面、清单过滤、单层确认、草稿保留、关闭焦点恢复、键盘搜索、任务停止，以及 1240×800 / 1024×700 布局。测试截图位于 `artifacts/full-parity/`。

原型源文件在 `prototype/`；`INTERACTION-PROTOTYPE.html` 是构建结果。没有直接复制 APK 的图标、原生二进制或解析表到发行包中。

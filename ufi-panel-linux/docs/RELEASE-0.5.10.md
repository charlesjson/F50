# UFI Panel Linux 0.5.10

历史图表的参考线吸附选中的真实采样时刻，并为当前指标显示高亮点，使参考线、浮层时间与数值对齐。缺失读数显示“—”并隐藏对应高亮点，零值仍可选中。时间轴标签对齐绘图区，窄图表允许日期换行。

修复断线、缺失指标或末次采样失败后，孤立的有效读数只执行移动路径而未绘制点的问题。现在逐个显示孤立读数，连续数据保持折线，缺失区间保持断开。概览和历史图表共用此修复。

温度、网速和流量的自动纵轴采用规整间隔，速率与字节量按 1024 单位计算；CPU 和内存保持 0–100%。例如温度以 0、20、40、60、80°C 显示，避免原来 66°C 上限造成刻度取整。长数据集的最大值通过遍历计算，避免展开大量参数。

悬停事件按动画帧合并，选中同一采样时复用时间、数值及浮层尺寸。浏览器实际界面中，同一帧连续 300 次鼠标事件从 300 次读数更新减少为 1 次；跨帧仍选中同一记录时不重复改写读数。移出或刷新时取消待处理事件，避免浮层重新出现。

验证：Node 自动测试 86 项通过，其中新增孤立读数和自动刻度回归测试；浏览器覆盖浅色/深色、1040/620 像素视口、2 倍像素密度、真实采样对齐、数据点高亮、零值、缺失值、鼠标移出与刷新性能。

原生 WebKit 使用真实 WebDriver 鼠标移动验证五类图表：参考线、高亮点坐标与原始记录一致，孤立读数在末次失败后保持可见，窄布局与深色主题的浮层正常显示。原生引擎同样将单帧 300 次鼠标事件合并为 1 次采样检查。历史查询、离线刷新、断线与重启后的记录持久化检查通过，模拟设备未发生写入。安装包内嵌的 47 项源码摘要与当前源码一致。

# UFI Panel Linux 0.5.14

插件配置页现在按设备保存网页会话，并在加载 UFI 网页之前提供客户端已验证的登录凭据。网页登录后的 UFI 令牌、中兴口令和登录方式写入独立的 `web-sessions.sqlite3`：使用系统密钥环提供的密钥和 AES-256-GCM 加密，记录按设备绑定，数据库权限为 `0600`。勾选连接设置中的「保存口令」且密钥环可用时持久保存；未勾选或无法解锁密钥环时仅在内存中使用。网页登录凭据不作为明文写入网页 localStorage。

关闭配置窗口、断开后连接同一设备，或重启客户端后重新连接同一保存的设备，都能恢复可用凭据。插件自己的浏览器偏好和持久 Cookie 保留在设备独立的 WebKit 数据目录。设备离线后，原采样恢复成功时会恢复网页内的有效凭据；加载失败的配置窗口会重新加载，已经加载好的页面保留配置编辑状态。不同设备、服务地址或端口不会收到 UFI 登录凭据；独立插件面板仍使用它自己的登录方式和会话。设备口令更改后应更新连接设置。

左键点击托盘图标，弹出独立的设备状态窗口。窗口无标题栏、不可调整大小、置顶且不占任务栏，靠近点击位置显示并限制在屏幕工作区内；点击其他窗口或按 Esc 自动隐藏，鼠标仅移出时保持显示。点击「打开管理台」恢复主窗口并收起状态窗口。

面板显示 CPU、内存、温度、今日用量、本月累计流量、实时下载和上传网速，以及 Wi-Fi 接入数。每项一行，名称左对齐、数值右对齐、单位固定在单独一列。格式与主界面左下角完全共用，沿用浅色／深色主题、缺失值、合法零值、暂停、过期和断开状态。复用原有采样和 Rust 缓存，打开窗口不发起设备请求；切换设备时不会沿用旧读数。

Linux 托盘改用 StatusNotifierItem，提供左键 Activate 和右键菜单，保留「显示管理台」「完整 UFI 面板」「退出」。旧常驻悬浮监控保持可用。状态窗口只接收筛选后的八项指标、更新时间和设备名称，没有设备口令、Cookie、完整设备响应或后台操作权限。

交互参考 [Magpie v0.1.593 的独立面板及失焦隐藏设置](https://github.com/yetone/magpie/blob/v0.1.593/internal/gui/app.go#L526)，由当前 Tauri / WebKitGTK 架构实现。

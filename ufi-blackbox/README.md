# UFI 网络黑匣子

给 F50 / UFI-TOOLS 完整版使用的轻量记录插件。设备常驻采集器负责记录，网页只负责查看；关闭浏览器后继续采样。

- 每 15 秒记录设备温度、CPU、内存、流量、蜂窝状态及实际可读的无线字段。
- 通常每 30 秒向 `223.5.5.5` 和 `119.29.29.29` 各发送一个小 ICMP 探测包，并向 `223.5.5.5` 查询 `www.baidu.com`。任一探测异常后，每 10 秒复测，最多持续 2 分钟，然后回到 30 秒。
- 记录可见的网络模式、频段、小区或 PCI 变化；RSRP 单次下降至少 12 dB、温度达到 75 °C 等变化进入时间线。温度回落到 70 °C 时记录恢复。
- 日志按 JSONL 写入，5 个分段，每段最多 4 MiB，合计最多 **20 MiB**。30 秒刷新一次写入缓冲，正常停止时补写；强制断电可能丢失最近尚未持久化的记录。
- 面板显示最近最多 720 条采样、探测和事件，支持导出所有已保留日志。重启采集器后加载保留的历史。

空的频段或小区字段表示固件未返回数据。探测无响应只是一项观测，不能单独证明蜂窝断网或 DNS 配置有误。这里的 DNS 检测针对指定解析器，不代表系统当前配置的全部 DNS 链路。插件不执行自动重连、重启、锁频或测速。

## 安装

开发机需要 Go 1.23+、Node.js 18+。设备需要 UFI-TOOLS 完整版及可工作的高级功能 / Root Shell。

```sh
sh scripts/build.sh
node scripts/install.cjs --connection /私有路径/connection.json
```

连接文件权限应为 `0600`，格式为 `{"address":"http://设备IP:2333","password":"UFI口令"}`，也支持已有的 SHA-256 `token`。不要将连接文件放入插件目录或公开仓库。

安装器先备份插件内容和开机脚本到本地 `private/`，上传后核对 SHA-256；保留其他插件和现有开机脚本，只新增本插件的菜单与启动段。刷新 UFI 网页，点击功能列表中的 **网络黑匣子**。

“导出全部日志”先准备文件，再点击“保存日志文件”。浏览器或嵌入式窗口限制文件保存时，也可以从开发机直接导出：

```sh
node scripts/export.cjs /私有路径/connection.json /保存路径/ufi-blackbox.jsonl
```

导出文件包括全部保留的日志，权限为 `0600`。它包含无线小区等记录，应按个人设备日志保管。

设备文件位于 `/data/adb/ufi-blackbox/`。目录为 `0700`，连接配置为 `0600`。浏览器插件不包含登录口令。控制接口是私有 Unix socket，不监听网络端口，网页通过 UFI 已有的鉴权 Root Shell 查看状态。持有 Root 或 UFI 高级 Shell 权限的人本来即可读取设备上的这些文件。

更改 UFI 登录口令后，重新运行安装器以更新后台采集器的连接配置。

开机启动挂接到 UFI 已有的 `/sdcard/ufi_tools_boot.sh`。该启动路径需要 UFI 原有的开机机制正常工作；普通的停止/启动验证不等于已验证整机断电重启。

## 停止和卸载

面板中的“停止记录”会停止当前采集进程并保留日志。开机启动段仍然存在，设备下次启动后会继续记录。

卸载菜单与启动段，并停止后台：

```sh
node scripts/install.cjs --connection /私有路径/connection.json --uninstall
```

日志保留在原目录。只在 UFI 插件列表中禁用或删除网页代码，不会停止已运行的采集器。

```sh

```
